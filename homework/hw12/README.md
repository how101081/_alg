# 第12週習題 - 解說本週上課的計算理論內容

本週範圍是《數學、語言、機器與程式》第 1～6 章，主軸只有一個問題：**演算法的能力極限在哪裡？**

## 1. 希爾伯特的問題（Ch.1）

1900 年巴黎 ICM 提出 23 題，資工最關心**第 2 題：算術公理的相容性**。

白話：能不能寫一支程式，自動證明所有數學定理？

- 作法：布林邏輯「事實 + 規則」，用**肯定前件 (Modus Ponens)** 前向推論
  - `A=>E`、`B=>F`、`E&F=>H` ➔ 一輪一輪加入新事實，直到不再產生新事實為止
- **希爾伯特計劃 (1920)** 五目標：形式化、完備性、一致性、保守性、確定性
- 結果：做不到（被後面三章先後否定）

## 2. 哥德爾的定理（Ch.2）

- **羅素悖論**：`A = {x | x ∉ x}` ➔ `A ∈ A ⟺ A ∉ A`，理髮師悖論，動搖樸素集合論
- 補救：一階邏輯 + ZFC 公理
- **1929 完備定理**：純一階邏輯中，所有恆真式都可被證明（還有希望）
- **1931 不完備定理**：只要加入整數算術 (PA)，就存在 `s` 既不能證真也不能證偽
  - 手法：用整數編碼製造自我指涉 ➔ 啟發後面圖靈的停機問題

## 3. 丘奇的函數（Ch.3）

- **λ-Calculus**：萬物皆匿名函數，沒有數字、布林等基本型態
- 兩規則：`α-conversion`（改參數名）、`β-reduction`（代入，`(λx.M)N → M[x:=N]`）
- 卻能疊出布林 (`TRUE/FALSE/IF`)、丘奇數、加減乘除、`CONS/CAR/CDR`，靠 **Y-Combinator** 做遞迴
- **不可解**：沒有程式能判定兩個 λ 表达式是否等價（可能無窮迴圈）

## 4. 圖靈的機器（Ch.4）

- **圖靈機 = FSM + 無限長磁帶**，讀寫頭可讀/寫/左右移動，能辨識 `aⁿbⁿcⁿ`
- 與 λ-Calculus 等價（**邱奇-圖靈論點**）
- **停機問題不可判定**：假設 `isHalt` 存在，構造唱反調的 `U`，執行 `U(U)` 必矛盾
- 本質與羅素悖論、哥德爾自我指涉相同

## 5. 喬姆斯基的語法（Ch.5）

用規則 `左式 → 右式` 生成語言（類似 BNF）。由弱到強：

| 類型 | 語言 | 對應機器 | 範例 |
| --- | --- | --- | --- |
| Type 3 | 正規 | FSM | `aⁿbᵐ`、正則表達式 |
| Type 2 | 上下文無關 | PDA | `aⁿbⁿ`、括號配對 |
| Type 1 | 上下文相關 | 線性有界圖靈機 | `aⁿbⁿcⁿ` |
| Type 0 | 遞歸可枚舉 | 圖靈機 | 任何可計算語言 |

即使最強的 Type 0，仍有限制（停機問題）。

## 6. 庫克的證明（Ch.6）

- **P**：多項式時間內能**算出**解；**NP**：多項式時間內能**驗證**解
- **歸約 (Reduction)**：把問題 A 轉成問題 B 來解
- **庫克定理 (1971)**：**SAT 是第一個 NP-Complete**；所有 NP 問題都能多項式時間轉成 SAT
  - 因此只要 SAT 能快速解，所有 NP 都能快速解
- **P = NP 至今未解**

## 一句話總結

從希爾伯特「用程式證明一切」的夢想出發，哥德爾、丘奇、圖靈證明**計算與邏輯有絕對極限**，再由喬姆斯基與庫克建立**語言能力**與**時間複雜度**的分類框架。
