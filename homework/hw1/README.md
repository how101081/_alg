# 習題 1：計算 2^n 的效率比較

課程：演算法 | 學生：楊丞皓 | 學號：06

## 題目來源
[ccc115a/_alg Issue #3](https://github.com/ccc115a/_alg/issues/3)

完成 `power2n.py` 中四種計算 2^n 的方法，觀察執行效率，找出哪個快、哪個慢、哪個出不來。

## 四種方法

| 方法        | 作法                              | 時間複雜度 |
|-------------|-----------------------------------|------------|
| 方法 1      | `return 2**n`（直接內建運算）      | O(1)       |
| 方法 2a     | `power2n(n-1) + power2n(n-1)`     | O(2^n)     |
| 方法 2b     | `2 * power2n(n-1)`                | O(n)       |
| 方法 3      | 遞迴 + 查表（memoization）        | O(n)       |

## 測試結果（n = 100）

主程式用 `time.perf_counter()` 計時，執行結果如下：

```
測試 n = 100
------------------------------------------------------------
方法 1       n=100 結果為 31 位數  耗時 0.000006 秒
方法 2b      n=100 結果為 31 位數  耗時 0.000039 秒
方法 3       n=100 結果為 31 位數  耗時 0.000056 秒
------------------------------------------------------------
方法 2a 呼叫次數為 2^100 ≈ 1.27e30 次，跑不完，
所以只測小 n 讓你看它到底有多慢:
方法 2a  n= 24 結果為 8 位數  耗時 3.468805 秒
推估 n=100 需要約 8.31e+15 年
------------------------------------------------------------
結果: 方法 1、2b、3 都很快，唯獨方法 2a 出不來!
```

## 結果與解釋

- **方法 1** 用 Python 內建的整數次方運算，一次就算出來，最快。
- **方法 2b** 每次只呼叫自己一次，深度 n，是 O(n)，n=100 秒殺。
- **方法 3** 靠查表避免重複計算，每個 n 只算一次，也是 O(n)，速度與 2b 相近。
- **方法 2a** 每次呼叫自己兩次，呼叫總數是 2^n（等比級數），n=100 需要約 2^100 次呼叫，永遠跑不完，**出不來**。

python power2n.py
