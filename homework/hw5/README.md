## 問題一：河內塔（[hanoi.py](hanoi.py)）

| 版本 | 做法 | 步數 |
|------|------|------|
| 遞迴 | 把 n-1 盤搬到輔助柱，搬最大盤，再把 n-1 盤搬過去 | 2ⁿ − 1 |
| 禁止遞迴（迭代） | 最小的盤沿著環狀順序移動，另一邊只做「兩柱間唯一合法的移動」 | 2ⁿ − 1 |

迭代版的小技巧：`n` 為奇數時小盤走 `A→C→B→A`，偶數時走 `A→B→C→A`。兩種版本搬法完全一樣。

```
n = 3
1. 盤 1: A -> C
2. 盤 2: A -> B
3. 盤 1: C -> B
4. 盤 3: A -> C
5. 盤 1: B -> A
6. 盤 2: B -> C
7. 盤 1: A -> C
共 7 步
```

## 問題二：符號微分（[sym_diff.py](sym_diff.py)）

數學式用 tuple 表示，`x` 是字串，數字是常數。`diff()` 依照微分公式遞迴拆解，再用 `simp()` 化簡。

| 原式 | 微分結果 |
|------|----------|
| `x^2` | `(2 * x)` |
| `x^2 + 3x` | `(2 * x) + 3` |
| `1 / x` | `-1 / (x * x)` |
| `x^3 * (x + 1)` | `(3 * x^2) * (x + 1) + x^3` |

乘法用乘法律 `(uv)' = u'v + uv'`，除法用 `(u/v)' = (u'v − uv') / v²`。

## 問題三：自製 map / filter / reduce + 泡沫排序（[fp.py](fp.py)）

`my_map`、`my_filter`、`my_reduce` 全部用**遞迴**寫（自己也不能用迴圈）。

泡沫排序也不用迴圈：
- `bubble_pass`：用 `my_reduce` 跑一趟，把最大值推到最後
- `bubble_sort`：遞迴對前 n−1 個再跑，直到只剩 1 個

```
排序前: [5, 2, 9, 1, 5, 6, 3]
排序後: [1, 2, 3, 5, 5, 6, 9]
```
