## 做法

SAT 就是能不能找到一組布林變數值，讓整個式子等於 1。
我直接把所有 2^n 種組合跑一遍（真值表法），每組都算一次，有等於 1 的就是 SAT，全部都是 0 就是 UNSAT。

## 執行結果

```
範例 1: (x1∨x2)∧(¬x1∨¬x2)  => 有解 (2 組)
範例 2: x1∧¬x1              => UNSAT
範例 3: 有解 (1 組)
範例 4: 三角形 2-著色        => UNSAT（三邊都要顏色不同，2 色不可能）
```

## 心得

暴力法很簡單，但變數一多 2^n 很快就爆了，所以才會有人研究更聰明的 SAT 演算法。
