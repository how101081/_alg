## 概念
SAT 就是問一組布林變數能不能讓整個式子算出 1，可以就是 SAT，全算 0 就是 UNSAT。
n 個變數只有 2^n 種組合，所以我直接把全部列出來一個一個算，就是真值表法。

## 公式（CNF）
- `v` 代表 x_v，`-v` 代表 not x_v
- 同一列（子句）用 OR 連，子句之間用 AND 連
- 例：`(x1∨x2)∧(¬x1∨¬x2)` → `[[1,2],[-1,-2]]`

## 程式
| 函式 | 功能 |
|---|---|
| `all_assignments(n)` | 列舉所有 2^n 種指派 |
| `eval_clause(clause,a)` | 算一個子句 |
| `eval_cnf(cnf,a)` | 算整個式子 |
| `print_truth_table(n,cnf)` | 印真值表 |
| `sat(n,cnf)` | 回傳滿足的指派 |

## 執行結果
- 範例 1（互斥 OR）：有解，2 組
- 範例 2（x1 ∧ ¬x1）：UNSAT
- 範例 3：有解
- 範例 4（三角形 2-著色）：UNSAT，因為三角形三邊都要求顏色不同，不可能

結論：真值表法簡單但變數一多就爆炸（2^n），這就是 SAT 是 NP 問題的原因。
