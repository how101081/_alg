# 第7週習題 - 優化演算法（旅行推銷員問題 TSP）

本作業使用五種不同的優化演算法來求解旅行推銷員問題（Traveling Salesman Problem, TSP），並在相同的測試資料下進行比較。

## 1. 問題說明

給定 $n$ 個城市以及各城市間的距離，找出一條「每個城市恰好走訪一次，最後回到起點」的最短路徑（Hamiltonian Circuit），使得路徑總長度最小。

## 2. 測試資料

- 城市數量：$n = 20$
- 座標：隨機產生於 $[0,100] \times [0,100]$，並固定隨機種子 `random.Random(42)`
- 距離：採用歐氏距離，預先計算 $20\times20$ 距離矩陣 $DIST$

所有方法都使用同一組城市與距離矩陣，以公平比較。

## 3. 五種解法

| 編號 | 方法 | 類型 | 說明 |
|---|---|---|---|
| 1 | 貪婪演算法（Nearest Neighbor） | 建構式啟發法 | 從起點開始，每次選擇「最近且未造訪」的城市，直到走完整圈。 |
| 2 | 改良法（2-opt） | 局部搜尋（確定性） | 以貪婪解為初始解，反覆找出兩條邊交叉的情況並反轉中間路徑，若路徑變短就採用，直到無法改善為止。 |
| 3 | 爬山演算法（Hill Climbing） | 隨機局部搜尋 | 隨機產生初始路徑，每次隨機交換兩個城市的位置，若新路徑較短就接受，否則還原。只接受更佳解。 |
| 4 | 模擬退火法（Simulated Annealing） | 機率式全域搜尋 | 類似金屬退火過程。初期溫度高時允許以機率 $P = e^{-\Delta/T}$ 接受較差解以跳出局部最佳，溫度逐漸降低後傾向只接受較好解。使用 2-opt 式的路徑反轉作為鄰域。 |
| 5 | 梯度下降法（Gradient Descent） | 連續鬆弛最佳化 | 將離散的路徑排列鬆弛為機率矩陣 $P_{k,i}$（第 $k$ 個位置造訪城市 $i$ 的機率），對 $W$ 以 row-softmax 得到 $P$，定義期望路徑長度加上「每個城市恰好造訪一次」的懲罰項，透過梯度下降最小化損失，最後以貪婪方式解碼回合法路徑。 |
