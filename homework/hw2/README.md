# 習題 2：求解遞迴方程式與演算法複雜度

課程：演算法 | 學生：楊丞皓 | 學號：06

## 題目來源
[ccc115a/_alg Issue #4](https://github.com/ccc115a/_alg/issues/4)

計算下列遞迴方程式的精確解，並求出對應的複雜度：

1. `T(n) = T(n-1) + 8, T(1) = 1`
2. `T(n) = 2T(n-1) + 9, T(1) = 1`
3. `T(n) = 2T(n/2) + 1, T(1) = 1`
4. `T(n) = T(n/2) + 1, T(1) = 1`

## 解答

### 1. T(n) = T(n-1) + 8, T(1) = 1

展開遞迴：
```
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = T(n-3) + 8*3
     ...
     = T(1) + 8(n-1)
     = 1 + 8n - 8
     = 8n - 7
```
**精確解：T(n) = 8n - 7**，例如 T(100) = 793。
**複雜度：O(n)**（例如循序迴圈跑 n 次）

### 2. T(n) = 2T(n-1) + 9, T(1) = 1

```
T(n) = 2T(n-1) + 9
     = 2(2T(n-2)+9) + 9 = 4T(n-2) + 18 + 9
     = 4(2T(n-3)+9) + 27 = 8T(n-3) + 63
     ...
     = 2^(n-1) T(1) + 9(1 + 2 + 4 + ... + 2^(n-2))
     = 2^(n-1) + 9(2^(n-1) - 1)
     = 10 * 2^(n-1) - 9
```
**精確解：T(n) = 10·2^(n-1) - 9**，例如 T(20) = 5,242,871。
**複雜度：O(2^n)**（指數成長，同二元樹層層分裂）

### 3. T(n) = 2T(n/2) + 1, T(1) = 1

令 n = 2^k，展開：
```
T(n) = 2T(n/2) + 1
     = 4T(n/4) + 2 + 1
     = 8T(n/8) + 4 + 2 + 1
     ...
     = 2^k T(1) + (2^(k-1) + ... + 2 + 1)
     = 2^k + (2^k - 1)
     = 2 * 2^k - 1
     = 2n - 1
```
**精確解：T(n) = 2n - 1**（n 為 2 的冪），例如 T(1024) = 2047。
**複雜度：O(n)**（每層工作量總和是線性，同二元樹走訪、merge sort 的 merge 部分）

### 4. T(n) = T(n/2) + 1, T(1) = 1

令 n = 2^k，展開：
```
T(n) = T(n/2) + 1
     = T(n/4) + 2
     = T(n/8) + 3
     ...
     = T(1) + k
     = k + 1
     = log2(n) + 1
```
**精確解：T(n) = log2(n) + 1**（n 為 2 的冪），例如 T(1024) = 11。
**複雜度：O(log n)**（每次砍半，同二元搜尋）

## 對應的演算法

| 遞迴方程式  | 對應演算法                    |
|-------------|-------------------------------|
| T(n)=T(n-1)+8 | 循序迴圈 / 循序掃描          |
| T(n)=2T(n-1)+9 | 暴力遞迴（如 power2n 方法 2a）|
| T(n)=2T(n/2)+1 | 二元樹走訪（每層都處理一次）  |
| T(n)=T(n/2)+1  | 二元搜尋 Binary Search       |
