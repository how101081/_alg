## 問題一：牛頓法求方程式根

我選的題目是用迭代法解方程式，程式在 [newton.py](newton.py)。

做法很簡單，就是牛頓法：先猜一個根，然後一直用切線把它往真正的根推。

```
x1 = x - f(x) / f'(x)
```

每算一次就把 x 更新，算到兩個值差很小就停。

### 執行結果

本題求 `x² - 2 = 0` 的根，也就是 √2：

```
用牛頓法求 x^2 - 2 = 0 的根（也就是 √2）

第  1 次: x = 1.5000000000
第  2 次: x = 1.4166666667
第  3 次: x = 1.4142156863
第  4 次: x = 1.4142135624
第  5 次: x = 1.4142135624

答案: x = 1.4142135624   (√2 = 1.4142135624)
```

只算了 5 次就收斂了。牛頓法收斂很快，因為每次差平方級縮小。

## 問題二：iter_framework.py 說明文件

這個程式最厲害的地方，是想把一大堆「迭代法」全部收進同一個框架裡。
以後想玩新的迭代法，只要寫**兩個函數**丟給它，剩下交給它跑就好。

核心只有一個 `generic_iterator(transition, is_converged, initial_state)`：

- `transition`：從現在的狀態推到下一步（就是「迭代一次」要幹嘛）
- `is_converged`：要不要停了？（例如兩個答案差一點點就停）
- `initial_state`：一開始從哪裡開始

它的流程就是無限迴圈：

```
做一次 transition → 檢查有沒有收斂 → 沒有就再來一次
```

下面示範了 9 種都是這種神邏輯的迭代法：

| # | 方法 | 在算什麼 |
|---|------|----------|
| 1 | 不動點迭代法 | 把一個函數一直套來套去 |
| 2 | 牛頓法 | 用切線找方程式的根（跟我的題目一一模一樣！）|
| 3 | 高斯-賽得爾法 | 解線性方程組 |
| 4 | 冪次迭代法 | 找矩陣最大的特徵值 |
| 5 | QR 演算法 | 把矩陣一直分解，拿到全部特徵值 |
| 6 | 龍格-庫塔法 | 解微分方程式 |
| 7 | PageRank | Google 排網頁名次的方法 |
| 8 | K-Means | 把資料分成幾群 |
| 9 | EM 演算法 | 估計隱藏的參數（丟硬幣的機率）|

心得：反正不管什麼迭代法，反正就是「一直重複、慢慢逼近」，只要寫好 `transition` 和收斂條件，
剩下的都交給這個框架，很像工廠的生產線。
