# 第9週習題 - 搜尋算法

本作業用搜尋法解決五個問題，全部寫在 `search.py`，只使用 Python 標準函式庫。

## 1. 老鼠走迷宮（DFS）

用深度優先搜尋（Depth-First Search）從 `S` 出發，每次往上下左右其中一個方向走，遇到牆壁 `#` 或走過的路就回頭，直到找到 `E`。

- 資料結構：遞迴 + `visited` 集合 + 路徑堆疊
- 優點：實作簡單、記憶體用量較少
- 缺點：找到的路徑不一定是最短路徑

## 2. 狼羊甘藍菜過河（BFS）

狀態用 `(狼, 羊, 甘藍菜, 農夫)` 表示，`0` 代表左岸、`1` 代表右岸。每次農夫可以自己過河，或帶一樣東西過河。

用廣度優先搜尋（Breadth-First Search）一層一層擴展狀態，因此第一次抵達目標狀態時，就是**最少過河次數**的解。

合法性規則：農夫不在的那一岸，若狼和羊單獨在一起（羊被吃），或羊和甘藍菜單獨在一起（菜被吃），該狀態就不合法。

## 3. 八皇后問題（DFS）

在 8×8 棋盤放 8 個皇后，使任兩個皇后不在同一列、同一行、同一條對角線。

用 DFS 一列一列放皇后，並用三個集合記錄已被占用的行、左斜線（`r-c`）、右斜線（`r+c`），快速判斷是否衝突。程式會找出全部 92 組解，並印出第一組。

## 4. NPC 搜尋玩家（A*）

在格子地圖上，NPC 要避開障礙物 `#` 走到玩家 `P` 的位置。

使用 A* 演算法：

- `g`：從起點走到目前的實際步數
- `h`：目前位置到目標的曼哈頓距離估計
- 優先展開 `f = g + h` 最小的節點

A* 比 BFS 更有效率，因為它會優先往目標方向搜尋。

## 5. IC 設計中的電路繞線（BFS）

把晶片看成格子，`A` 是起點針腳、`B` 是終點針腳，`#` 是障礙物（其他元件或已有線路），要在避開障礙物的情況下連接 `A` 和 `B`。

這裡用 BFS 找**最短繞線路徑**（線長最短）。實務上還可以用 A*、迷宮繞線（Maze Routing）、Lee Algorithm 等方法，並加入線寬、多層金屬、避免交叉等限制。
